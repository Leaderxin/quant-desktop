常见问题

关于数据来源、隐私、许可与安装的常见疑问。没找到答案的话，欢迎到 GitHub Issues 提问。

数据与隐私

使用 QuantDesktop 需要注册账号吗？

不需要。应用没有账号系统，下载装完直接就能用，也没有任何统计埋点。

会收集我的数据吗？

不会。自选股、界面偏好、窗口位置全部保存在本机 SQLite 数据库，不上传任何服务器，卸载应用后随之删除。

行情数据从哪里来？可靠吗？

来自腾讯证券与新浪财经的公开行情接口，两个数据源互为备份，其中一个异常时自动回退到另一个。数据仅供参考，不构成投资建议。

卸载后本地数据会残留吗？

Windows 下数据在 %APPDATA%\quant-desktop，便携版在程序目录的 data 子目录下；卸载应用不会自动删除这些文件，手动删掉该目录即可彻底清除。

费用与许可

真的完全免费吗？

个人使用完全免费，没有内购、没有会员、没有功能墙。项目采用 PolyForm Noncommercial 非商业开源许可，商业使用需要获得作者授权。

可以用在公司或商业环境里吗？

不可以直接商用。许可是 PolyForm Noncommercial 1.0.0，个人使用、学习、修改、分发免费，商业使用需先取得作者授权。它不是 MIT。

有广告或弹窗推广吗？

没有。应用不含任何广告、推送或第三方分析 SDK，不会推销理财产品，也没有需要关闭的启动页。

系统与使用

支持哪些操作系统？

Windows 10 与 11、macOS（Intel 与 Apple Silicon），以及 Linux（glibc 2.35 及以上，Ubuntu 22.04 基线）。

支持哪些市场？港股美股能看吗？

目前覆盖沪深京三市的个股、指数与 ETF。港股与美股在规划中，尚未支持。

刷新频率是多少？可以自己调吗？

按交易时段自动调节，不需要手动设置：开盘探测每 2 秒、正常交易 2 秒、盘前与午休 5 到 10 秒、连续无变化或节假日降到 30 秒。

Windows 提示「已保护你的电脑」是怎么回事？

这是 SmartScreen 对未购买代码签名证书的独立软件的统一提示，不是报毒。点「更多信息」再点「仍要运行」即可；也可以改从 Microsoft Store 安装。

关闭窗口后应用去哪里了？

点关闭只是收进系统托盘，行情条和后台轮询继续运行。要彻底退出，右键托盘图标选「退出」。
