最受欢迎

悬浮行情条：上班族的「余光看盘」

一枚常驻桌面的迷你行情条，始终置顶于所有窗口，无边框、不占任务栏。 把它拖到副屏边缘或任务栏旁，工作时余光一扫就够了 —— 它看起来就像桌面的一部分。

  • 每 3 秒自动轮播自选股：名称 / 现价 / 涨跌幅，每屏 1–10 只可调
  • 轮播范围自定 —— 跨分组挑选播报标的、拖拽调整顺序，不需要的逐只关掉
  • 可设为透明背景 —— 底板、圆角与阴影一并去掉，只留数字浮在桌面上
  • 拖到哪儿，下次就在哪儿 —— 位置自动记忆，鼠标悬停自动暂停
  • 深浅主题实时同步，单击行情条立即恢复主窗口

自选管理

分组、列、排序，都按你的习惯来

输入 6 位代码即时搜索，覆盖沪深京三市个股、指数与 ETF。

  • 自选分组 —— 双击标签就地重命名，右键菜单增删与调序；同一只股票可同时属于多个分组，在每个分组里的位置各自独立
  • 列随你挑 —— 显示哪些列、列的先后、默认按哪列排序都在设置里调；点列头即可临时改排
  • 市场标签（沪A / 深A / 北A / 沪指 / ETF…）让同代码的指数与个股一眼可辨
  • 跨数据源智能回退 —— 一个源搜不到，自动换源再试
设置页

把界面调成你的样子

六个分区横向排列：指数区、市场概览、自选列表、行情条、通用、关于。 点状态栏的齿轮进入，改完回到看盘界面即生效，不必重启。

  • 排序项都能拖拽，也能用 Alt + ↑ / ↓ 或每行按钮 —— 键盘一样排得动
  • 说明文字常驻在每一行下方，不藏在悬停提示里

  • 配色方案可互换 —— 红涨绿跌（A 股习惯）与绿涨红跌（欧美习惯）一键切换，K 线图一并跟随
  • 等宽数字字体，价格与涨跌幅成列对齐，刷新时不跳动
看不见的功夫

好工具的体验，藏在看不见的细节里

按交易时段自动调节刷新频率，快慢有度，不浪费一滴带宽和电量。

状态 轮询间隔 说明
开盘快速探测2 秒 × 3 次确认交易是否活跃
正常交易2 秒实时跟踪价格变化
盘前 / 午休5 ~ 10 秒适度降频
连续无变化30 秒自动进入空闲态
节假日 / 周末30 秒智能休眠

双数据源

腾讯证券（默认）+ 新浪财经（备用），顶栏一键切换、即时刷新，单源异常自动回退。

离线缓存

行情写入本地 SQLite，重启立即恢复上次报价，打开就有数据，不用干等网络。

窗口位置记忆

主窗口与行情条的位置尺寸自动保存，重启原位恢复，跨显示器自动边界保护。

托盘常驻

关闭窗口不退出，安静缩到系统托盘；支持开机自启，也可以配一个全局老板键一键隐藏。

自动更新

新版本自动检测、一键安装，交易时段智能抑制弹窗，不打断盯盘。

技术架构

用 Tauri 2，而不是把浏览器打包进去

Rust 后端负责行情抓取、SQLite 存储与自适应调度，Vue 3 驱动主窗口与悬浮行情条两个独立窗口。

常见问题

你可能想问的

行情数据从哪里来？可靠吗？
来自腾讯证券与新浪财经的公开行情接口，双数据源互为备份，接口异常自动回退。 数据仅供个人参考，不构成任何投资建议。
真的完全免费吗？
个人使用完全免费。项目采用 PolyForm Noncommercial 非商业开源许可 —— 你可以自由使用、学习和修改，商业使用需获得作者授权。
需要注册账号吗？会收集我的数据吗？
不需要任何账号，也没有任何统计埋点。自选与配置只存储在本机 SQLite 数据库，不采集、不上传任何个人信息。 详见隐私说明。
支持哪些系统？
Windows 10 / 11、macOS（Intel 与 Apple Silicon）、Linux（Ubuntu 22.04+ / glibc 2.35+ 基线）。
