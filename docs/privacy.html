QuantDesktop 隐私政策

最后更新日期：2026 年 9 月 15 日

概要：QuantDesktop 不收集、不存储、不上传任何用户个人信息。 应用没有账号系统，不含广告、推送和任何第三方分析 / 追踪 SDK。你的所有配置仅保存在本机。

一、数据收集

QuantDesktop 不收集、不存储、不上传任何用户个人信息，包括但不限于：

  • 姓名、邮箱、电话号码等身份信息
  • 地理位置、IP 地址
  • 设备标识符、硬件指纹
  • 浏览记录、使用习惯、操作行为数据

应用没有用户注册 / 登录功能，任何情况下都无法将使用行为关联到具体个人。

二、行情数据请求

应用展示的股票行情数据来自第三方公开市场数据接口。为保证行情实时性，应用会以匿名方式定时请求上述接口，请求中只包含股票代码等行情参数，不包含任何用户身份信息。

三、更新检查

通过 GitHub 渠道安装的版本会定期向 GitHub Releases 请求最新版本元数据以检查更新。该请求同样不包含任何个人信息。通过 Microsoft Store 安装的版本使用系统自带的 Store 更新机制。

四、本地存储

你的全部使用数据仅保存在本地计算机上，不会上传到任何服务器，卸载应用后即随之删除：

  • 自选股列表（本地 SQLite 数据库）
  • 界面偏好（主题、数据源选择、行情条开关等设置）
  • 窗口位置与尺寸
  • 最近行情快照缓存（用于加速下次启动时的显示）
  • 本地运行日志（仅写入本机日志文件，用于排查问题，不外发）

五、第三方服务

本应用不集成任何第三方分析、广告、推送或追踪 SDK。除第二节所述的行情数据接口和第三节的更新检查外，应用不与任何服务器建立连接。

六、免责声明

本应用展示的行情数据仅供参考，不构成任何投资建议。数据可能存在延迟或误差，投资有风险，入市需谨慎。
